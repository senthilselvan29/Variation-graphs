# Variation Graphs (மாறுபாட்டு வரைபடங்கள்)

Interactive direct and inverse variation graph activities, in Tamil and English.

**Author:** J. Senthil Selvan, B.T. Maths, Govt Boys Hr. Sec. School, Thirumayam, Pudukkottai District

Single-file web app (`index.html`). It needs no internet connection once loaded, and no fonts or libraries are downloaded.
